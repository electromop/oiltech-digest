## Аудит путей ОС (до правки)

| Путь | Кто | Доходило до обучения |
|---|---|---|
| Форма ОС на карточке радара | только админ | да — единственный путь |
| «В дайджест» на карточке радара | все | нет |
| «Шум / Дубликат / В дайджест» в ленте | все | нет: события пишутся, читателя нет |
| Звёзды, причины, комментарии к статьям и источникам | все | нет |

Дефекты обучения радара:
- новый вердикт не заменял прежний;
- отказы вытеснялись одобрениями из подсказки судьи (сортировка по весу, лимиты 120/200);
- «Дубль #ID» не скрывал карточку — отзыв делал её «разобранной»;
- исправленные заголовок и суть не попадали на карточку.

Баг выпуска: сигнал радара уходил в `monthly_digest_items.article_id` — ошибка внешнего ключа или чужая статья.

## Что сделано (PR #77)

- **ОС на радаре — для всех пользователей** (`api.py`, форма без `isAdmin`).
- **Смена вердикта гасит прежний.**
  - Строки до 28.09 узнаются по своему отзыву (`facts.feedback_event_id` → событие карточки): заголовок мог
    смениться.
  - Отказ гасит подсказки поиска этой карточки.
- **«В дайджест» — пример «Сильный сигнал»** (`origin=digest_selection`, свой у каждого пользователя):
  подсказка поиска идёт в теме карточки, «Убрать» гасит только этот пример. Вердикты людей из формы выбор
  не трогает — «последнее слово» за явным отзывом.
- **Ключ памяти вердикта и дубля — по номеру карточки** (было по заголовку: две карточки с одинаковым
  заголовком и вердиктом делили одну строку).
- **«Дубль #ID» скрывает карточку сразу** (`mark_signal_merged(respect_review=False)`).
- **Отказы доходят до судьи.**
  - В выборку — одобрения и отказы поровну (`list_signal_verdict_memory_balanced`), и в снимке для NL, и на ядре.
  - В подсказке раздел отказов — настоящие отказы первыми (#78, см. «Выкат»).
- **Вердикт «Не тот блок»** (`wrong_block`, встреча 21.09, решение 5): отказ с понятной судье подписью.
- **Правки заголовка и сути из ОС** накладываются при чтении — в списке радара и в выпуске. Следующий прогон
  радара их не перепишет.
- **Карточка без единой ссылки не показывается** (сигнал 97).
- **Выпуск:** у сигнала `item_type=signal`, `signal_id`, в `article_id` он не пишется; после сохранения
  черновика не пропадает.
- **Кандидат-источник:** решение оператора (одобрен, отклонён, отложен) повторная находка агентом не сбрасывает.
- **Экран радара:**
  - блоки по тематикам, как «Бизнес-сигналы»;
  - 38 ранних карточек 13.09 со свободной темой — отдельным блоком в конце, в фильтр тем не попадают;
  - «Поступил: дата» вместо строки плашек-издателей;
  - «Не тот блок» в оценках.

## Ревью свежим контекстом (два независимых) → `31fd9f2`, повторная проверка → `7e2f150`

| Находка | Исправление |
|---|---|
| «Дубль #ID» прятал карточку, выбранную в выпуск: исчезала с экрана, оставалась в выпуске | такую карточку склейка не прячет; скрытые дубли в выпуск не попадают; `cli unmerge-signal <id>` |
| Память гасилась и по заголовку — «Дубль» на одной карточке гасил одобрение другой с тем же заголовком | только по номеру карточки: `signal_id` или её отзыв |
| Отметить и снять «В дайджест» — отказ человека пропадал; снятие одним пользователем гасило пример другого | пример свой у каждого; выбор вердикты людей не трогает (`7e2f150`). Первая правка — «вернуть отказ после снятия» — повторная проверка забраковала: список затирался, старый отказ воскресал поверх нового вердикта |
| Ключ памяти вердикта по заголовку — у одинаковых заголовков одна строка | ключ по номеру карточки (`7e2f150`) |
| Событие «в дайджест» занимало обучающие примеры карточки | больше не привязывается |
| Все статьи черновика скрыты — выпуск из одних сигналов | прежний откат к текущей подборке |
| Раскрытый поиском блок не сворачивался | ручное сворачивание сильнее авто-раскрытия |
| Подпись «склейка не прошла» называла не ту причину, если карточка уже скрыта | подпись называет все три причины, список перечитывается (`b75b7c6`) |
