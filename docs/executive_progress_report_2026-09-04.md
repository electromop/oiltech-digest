# OilTech Digest: отчет о проделанной работе

Дата: 04.09.2026  
Период: последние две недели разработки  
Фокус: качество отбора сигналов, агент поиска источников, перевод нефтегазовой терминологии, готовность к демонстрации.

## 1. Краткий вывод

За период продукт был существенно усилен не косметически, а по ключевым производственным контурам:

- появился управляемый агент поиска новых источников;
- добавлен экран управления агентом и кандидатами источников;
- усилена проверка качества источников: регулярность, доступность, шум, дубли, рекомендации;
- оформлена документация пайплайна агента и правил его действий;
- закрыт отдельный критичный блок качества перевода нефтегазовой терминологии;
- добавлены воспроизводимые проверки: 100 терминологических кейсов, валидатор словаря, отчеты CSV/Markdown.

Итог: система стала ближе к промышленному инструменту мониторинга, а не просто к парсеру новостей.

## 2. Что было сделано по агенту источников

| Направление | Что сделано | Бизнес-эффект |
|---|---|---|
| Поиск новых источников | Агент умеет искать кандидатов источников по темам, запросам и памяти прошлых запусков | Система может расширять охват без ручного поиска источников с нуля |
| Планировщик действий | Добавлен agent loop: выбор тем, запросов, проверок, остановок и бюджетов | Уменьшается хаос ручного управления, появляется контролируемая автоматизация |
| Память агента | Учитываются темы, домены, запросы, стратегии, пользовательские правила | Агент не повторяет одни и те же ошибки и запоминает полезные направления |
| Проверка кандидатов | Добавлена песочница: пробный парсинг, оценка материалов, объяснение качества | Источник не попадает в каталог без проверки на реальных материалах |

| Бюджеты и предохранители | Ограничения по дневным запускам, кандидатам, оценкам | Защита от бесконтрольных расходов и бесконечного обхода сети |

## 4. Что сделано по переводу нефтегазовой терминологии

Ключевая проблема: универсальный ИИ-перевод часто ошибается в отраслевых терминах. Например, переводит `fracking` как "фракинг", хотя для нефтегазового дайджеста нужен термин "ГРП".

Сделано:

- создан нефтегазовый словарь терминов;
- словарь вынесен в отдельный JSON-файл: `oiltech_digest/processing/domain_glossary.json`;
- summary и перевод заголовков получают релевантные термины прямо в prompt;
- после ответа модели работает детерминированный слой исправления плохих терминов;
- сборка дайджеста дополнительно нормализует старые карточки из базы перед PDF/DOCX/HTML;
- добавлены команды проверки и ремонта терминологии.

Примеры:

| Оригинал | Было плохо | Стало правильно |
|---|---|---|
| `hydraulic fracturing` | Компания расширила фракинг | Компания расширила ГРП |
| `workover` | Ворковер увеличил добычу | КРС увеличил добычу |
| `well completion` | Завершение скважины ускорило ввод | Заканчивание скважины ускорило ввод |
| `reservoir` | Добыча из резервуара выросла | Добыча из пласта выросла |
| `drilling mud` | Новая буровая грязь снизила потери | Новый буровой раствор снизил потери |
| `bottomhole assembly / ROP` | Оптимизация bottomhole assembly повысила ROP | Оптимизация КНБК повысила механическую скорость проходки |
